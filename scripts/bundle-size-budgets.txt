# Bundle-size budgets for scripts/guard-bundle-size.sh.
#
# This file is the single source of truth for every Astro app's threshold.
# Nothing else may hardcode one — not a package.json build script, not a
# workflow step, not the wiki. scripts/guard-bundle-size.sh <package-dir> looks
# its record up here; scripts/guard-bundle-size.sh --all walks every record.
#
# One record per line: <package-dir> <worker|static> <threshold>
#   <package-dir> is the repo-relative path used everywhere else this app is
#     named (e.g. "cire/host") — also what a caller running from inside the
#     package (build scripts pass ".") gets resolved to before the lookup.
#   <worker|static> — see guard-bundle-size.sh's own comment for what each
#     mode measures and why they differ.
#   <threshold> — gzip byte ceiling. Comment after the line's own trailing
#     `#` records the measured reading it was set from, so the headroom
#     arithmetic stays checkable without a rebuild.
#
# Re-baselining after an intentional bundle change: build (clean, alone),
# read the printed total, and edit ONLY this line — package.json, ci.yml and
# deploy.yml all read through this file, so there is nowhere else to update.
# Set the new threshold to the new measured total plus headroom smaller than
# a motion-class dependency (~21.3 KB gzip minified — see
# guard-bundle-size.sh's comment for the full reasoning); ~11.7 KB is the
# figure every row below uses and is a reasonable default to keep using.
#
# A re-measure is not automatically a re-baseline, and the two cases below are
# why the distinction matters.
#
# All four cire apps joined the token contract with their thresholds unchanged,
# so their headroom TIGHTENED — ~7.4 KB (host), ~4.3 KB (vendor), ~8.5 KB
# (invites, whose two modal conversions moved it a little in each direction and
# left it ~0.3 KB below where it started) — rather than the ~11.7 KB default.
# That is the right direction: the rule caps headroom (it must stay smaller than
# the smallest mistake the guard exists to catch) and does not require any, so
# raising a ceiling to restore the default would only make the guard looser.
#
# `cire/landing` went the other way and so its threshold moved. Converting its
# demo sheet to `@shared/ui`'s `Modal` deleted the one module importing `motion`,
# and the library left the bundle with it: 185,383 -> 164,847 bytes. Leaving
# 189,324 in place would have banked a 24.5 KB gap, which is larger than the
# mistake this guard exists to catch, so the threshold followed the measurement
# down to measured + ~11.7 KB.
#
# Blank lines and lines starting with # are ignored.

cire/invites   worker  175000   # measured 166510
cire/host      static  252653   # measured 240953
cire/vendor    static  81644    # measured 77305
cire/landing   static  176547   # measured 164847
musubi/landing static  26865    # measured 15206
pulse/landing  static  28366    # measured 16683
