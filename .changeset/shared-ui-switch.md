Add `Switch` (`@shared/ui/ui/switch`), an on/off control on Kobalte's switch
for a change that takes effect at once. It is controlled, so it shows only the
value it is given; `readOnly` keeps it focusable and at full contrast for
someone who may read a setting but not change it, and `busy` holds it
read-only and announced as busy while a change saves.
