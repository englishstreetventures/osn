Cire's error lines, standing notes, badges, tags and run-sheet flags are drawn by the shared parts. Every hand-written error line is an inline danger `Notice` with a circled icon and the word "Error" read before it; on the Classic invite's centred column a one-line error stays centred and a longer one runs from the form's start. An error line about one field — a refused claim code, a missing first name, an address the server refused, an unticked consent box, a missing price — is named by that field, which is marked invalid while the line is about it; in the portal that turns the price box's border red. The palette's notes, the RSVP sheet's closed and preview notes and the sign-in and demo preview notes are small `Notice` boxes, and the palette's contrast warning is a warning. The guest site's preview notes sit on the plain surface. The bordered pills — the top bar's and a co-host's role, "Connected", "New", an invite section's state, "Applies immediately", a seated guest's reply, "RSVPs closed" — are outlined `Chip` pills; the category and status tags are `Chip` tags, a gift that has ended ("No longer coming", "Refunded") outlined in red; the run sheet's flags are `Chip` tags. The role badges explain themselves on hover instead of through a `title`. The vendor portal's design notes say so. In the light theme the portals' error red is a step darker (`oklch(46% 0.15 25)`), so an error box or line reads at least 4.5:1 on every ground they set one on, a card's sunk well included; the dark theme keeps its red.
