`Button`'s corner now comes from a role each app sets, ready for pill actions, and its labels are no longer uppercased. The corner leaves the shared base and is chosen once per variant and size: every action variant takes `rounded-ui-control`; `chip` takes `rounded-ui-pill`, so it stays round beside the event sheet's round close button whatever an app maps `control` to; `tile`, `field` and the `swatch` size take `rounded-ui-field`. Each class string carries exactly one corner, `base:`-prefixed, so a caller's plain `rounded-*` still wins. The boxed sizes drop `uppercase` and wide tracking for a medium weight at normal tracking, and the `sm`, `md` and `lg` side padding widens a step so the round ends sit balanced. A hover now fades only the text, background, border and underline colours, over the app's `--dur-fast` (100ms in an app that sets none), so the focus ring shows the moment focus lands rather than fading in. The exports are unchanged. Until each app maps `--ui-radius-control` to a pill, its buttons keep their current corner. Labels show as each call site spells them, with no uppercase transform; call sites that still write Title Case, such as "Event Details", keep it until their text is rewritten. In `@cire/invites`, the event card's browser test now measures the wrapped action row on a 320px phone, and the two-column desktop card at 1280px, where the labels sit side by side.
