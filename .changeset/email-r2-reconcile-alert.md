New template `r2-reconcile-alert`: the operator email for cire's R2 orphan reconcilers — a run held on a halving of referencing rows, a hold that has ended, a bucket's stop object in place, or a tier with the reconcilers disabled. It carries counts, the bucket's name, the tier and the command to stop or resume, never an object key or guest data.
